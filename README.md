# Tạo giáo án tự động – Lớp 2

Công cụ PowerShell + Microsoft Word: ghép giáo án tuần từ kế hoạch dạy học khối và các file giáo án từng môn, rồi chuẩn hoá theo khung mẫu.

- Chạy: bấm đúp `CongCu/TAO GIAO AN.bat`, nhập số tuần.
- Hướng dẫn đầy đủ: [CongCu/HUONG_DAN.md](CongCu/HUONG_DAN.md)
- Cấu hình (thời khoá biểu, ngày đầu năm học, chế độ từng môn): `CongCu/cauhinh.json`

Kho này chỉ chứa công cụ. Thư mục `LỚP 2`, file kế hoạch khối và các file giáo án tuần không được đưa lên. Cần đặt chúng cạnh thư mục `CongCu` trên máy thì công cụ mới chạy được.
